# Semt Pazar Alanları — Yasal Sayfalar

Bu depo yalnızca **Semt Pazar Alanları** mobil uygulamasının yasal sayfalarını
barındırır. Uygulamanın kaynak kodu burada değildir.

- [Gizlilik Politikası](https://donanimlabs.github.io/semt-pazar-yasal/gizlilik.html)
- [Kullanım Koşulları](https://donanimlabs.github.io/semt-pazar-yasal/kullanim-kosullari.html)

Bu adresler Google Play ve App Store kayıtlarında kullanılmaktadır.

> Sayfaların ikinci bir kopyası uygulamanın içinde de bulunur (Ayarlar → Gizlilik
> Politikası / Kullanım Koşulları). İkisi aynı metni taşımalıdır.
